# 题目描述
给你一个字符串数组，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。

**示例 1:**<br>
&emsp; **输入:** strs = ["eat", "tea", "tan", "ate", "nat", "bat"]<br>
&emsp; **输出:** `[["bat"],["nat","tan"],["ate","eat","tea"]]`

**示例 2:**<br>
&emsp; **输入:** strs = [""]<br>
&emsp; **输出:** `[[""]]`

**示例 3:**<br>
&emsp; **输入:** strs = ["a"]<br>
&emsp; **输出:** `[["a"]]`

# 我的解法
## 设计思路
遍历输入数组，对每个字符串进行**排序**以获取其键，然后将其添加到字典中对应键的列表里。最后，将字典中所有的值（即分好组的列表）收集起来返回。

## 代码实现
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        dict_str={}
        for i in range(len(strs)):
            sorted_str=self.str_sorted(strs[i])
            if sorted_str in dict_str:
                dict_str[sorted_str].append(strs[i])
            else:
                dict_str[sorted_str]=[strs[i]]
        
        return list(dict_str.values())

    # 字符串排序
    def str_sorted(self,str: str):
        charts=sorted(str)
        str="".join(charts)
        return str
```

# 最佳解法
## 设计思路
利用**质数乘积的唯一性**来对字母异位词进行分组。<br>
具体方法是：<br>
1、**质数映射：** 将26个小写字母分别映射到一个唯一的质数。<br>
2、**计算特征值：** 遍历每个字符串，将其包含的所有字母对应的质数相乘，得到一个唯一的乘积。根据算术基本定理，这个乘积可以唯一地代表该字符串中字母的种类和数量。<br>
3、**哈希分组：** 使用一个哈希表，以计算出的乘积作为键（Key），将具有相同乘积（即为字母异位词）的字符串归入同一个列表中。<br>

## 代码实现
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        dict_score={
            'a':2,'b':3,'c':5,'d':7,'e':11,'f':13,'g':17,
            'h':19,'i':23,'j':29,'k':31,'l':37,'m':41,'n':43,
            'o':47,'p':53,'q':59,'r':61,'s':67,'t':71,
            'u':73,'v':79,'w':83,"x":89,'y':97,'z':101
        }
        
        dict_strs={}
        for i, str in enumerate(strs):
            now=1
            for j in str:
                now *= dict_score[j]
            if now in dict_strs:
                dict_strs[now].append(str)
            else:
                dict_strs[now]=[str]
        
        return list(dict_strs.values())
```
