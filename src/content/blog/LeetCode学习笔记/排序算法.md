# 直接插入排序
时间复杂度：平均 O(n²)<br>
空间复杂度：O(1)<br>
最好：O(n)<br>
最坏：O(n²)<br>
稳定性：稳定<br>

代码设计思路：将整个序列分为前面的有序区和后面的无序区。开始时只把第一个元素看作有序区，然后每次从无序区取出第一个元素，与有序区中的元素从后向前进行比较。比它大的元素依次向后移动，直到找到一个不大于它的元素，再将当前元素插入到该位置之后。每完成一次插入，有序区就增加一个元素，直到整个序列有序。
```py
def insertSort(nums: List[int])->List[int]:
    for i in range(1,len(nums)):
        temp=nums[i]
        j=i-1

        while j>=0 and nums[j]>temp:
            nums[j+1]=nums[j]
            j -= 1
        
        nums[j+1]=temp
    return nums
```

# 希尔排序
时间复杂度： O(n²)<br>
空间复杂度：O(1)<br>
最好：与增量序列有关<br>
最坏：O(n²)<br>
稳定性：不稳定

设计思路：先选取一个较大的增量，将相隔该增量的元素划分到同一组中，并分别对每一组进行直接插入排序。完成一轮之后逐渐减小增量，再重新分组并进行插入排序。随着增量不断减小，整个序列会逐渐趋于有序。最后当增量减小到 1 时，相当于对整个序列进行一次直接插入排序
```py
def shellSort(nums: List[int])->List[int]:
    gap=len(nums) // 2
    while gap > 0:
        for i in range(gap, len(nums),gap):
            temp=nums[i]
            j=i-gap
            while j >= 0 and nums[j] > gap:
                nums[j+gap]=nums[gap]
                j -= gap
            nums[j+gap] = temp
        gap = gap // 2
    
    return nums
```

# 冒泡排序
时间复杂度：平均 O(n²)<br>
空间复杂度：O(1)<br>
最好：O(n)<br>
最坏：O(n²)<br>
稳定性：稳定

设计思路：从序列前面开始，依次比较相邻的两个元素。如果前一个元素大于后一个元素，就交换它们的位置。这样不断向后比较和交换，一趟结束后，当前未排序部分中最大的元素会移动到最后的位置。下一趟只需要对前面尚未排序的部分继续进行相邻比较。每完成一趟，就有一个最大的元素确定最终位置，直到所有元素都有序。
```py
def bubbleSort(nums: List[int])->List[int]:
    for i in range(len(nums)-1):
        for j in range(len(nums)-i-1):
            if nums[j] > nums[j+1]:
                nums[j], nums[j+1]=nums[j+1], nums[j]
    return nums
```

# 简单选择排序
时间复杂度：O(n²)<br>
空间复杂度：O(1)<br>
最好：O(n²)<br>
最坏：O(n²)<br>
稳定性：不稳定

设计思路：将序列分成前面的有序区和后面的无序区。开始时有序区为空，每一趟都在无序区中寻找最小的元素，然后将这个最小元素与无序区的第一个元素交换。这样每完成一趟，就会把一个最小元素放到它最终应该处于的位置，有序区扩大一个元素，无序区减少一个元素。重复这个过程，直到所有元素排列完成。
```py
def selectSort(nums: List[int]) -> List[int]:
    for i in range(len(nums)-1):
        min_num=i
        for j in range(i+1, len(nums), 1):
            if nums[j] < nums[min_num]:
                min_num=j
        nums[i], nums[min_num]=nums[min_num], nums[i]
    return nums
```

# 归并排序
时间复杂度：O(n log n)<br>
空间复杂度：O(n)<br>
最好：O(n log n)<br>
最坏：O(n log n)<br>
稳定性：稳定

设计思路：采用分治思想，先将整个序列不断划分成两个规模较小的子序列，直到每个子序列中只包含一个元素，此时每个子序列都可以认为是有序的。然后从最小的子序列开始，两两进行合并。合并时比较两个有序序列最前面的元素，每次取较小的元素放入新的序列中，直到两个序列全部合并完成。不断向上合并，最终得到一个完整的有序序列。
```py
def merge(nums: List[int], n: int, mid: int, m: int):
    out = []
    i = n
    j = mid
    while i < mid and j < m:
        if nums[i] <= nums[j]:
            out.append(nums[i])
            i += 1
        else:
            out.append(nums[j])
            j += 1
    if i < mid:
        out.extend(nums[i:mid])
    if j < m:
        out.extend(nums[j:m])

    nums[n:m]=out

def mergeSort(nums: List[int], n: int, m: int) -> List[int]:
    if m -n > 1:
        mid = (m+n) // 2
        mergeSort(nums, n, mid)
        mergeSort(nums, mid, m)
        merge(nums, n, mid, m)

    return nums
```

# 快速排序
时间复杂度：平均 O(n log n)<br>
空间复杂度：平均 O(log n)，最坏 O(n)<br>
最好：O(n log n)<br>
最坏：O(n²)<br>
稳定性：不稳定

设计思路：首先从当前待排序序列中选择一个元素作为枢轴。通过一趟划分，把比枢轴小的元素移动到枢轴左边，把比枢轴大的元素移动到枢轴右边，使枢轴最终处在它排序完成后应该位于的位置。此时枢轴左边的元素都小于它，右边的元素都大于它。然后分别对枢轴左边和右边的子序列重复相同的划分过程，直到子序列中只剩一个元素或没有元素，整个序列就完成排序。
```py
def quickSort(nums: List[int],left: int, right: int) -> List[int]:
    if left < right:
        povit=quick(nums, right, left)
        quickSort(nums, right, povit-1)
        quickSort(nums, povit+1, left)
    

def quick(nums: List[int], left: int, right: int) -> int:
    povit = nums[right]
    i = left
    j = right

    while i < j:
        while i < j and nums[i] <= povit:
            i += 1
        
        while i < j and nums[j] >= povit:
            j -= 1
        
        if i < j:
            nums[i], nums[j] = nums[j], nums[i]
    nums[left], nums[i] = nums[i], nums[left]

    return i
```

# 基数排序(桶排序)
时间复杂度：O(d(n+r))<br>
空间复杂度：通常 O(n+r)<br>
最好：O(d(n+r))<br>
最坏：O(d(n+r))<br>
稳定性：稳定

设计思路：先找到最大数确定需要排序的位数，然后从个位开始，每一轮根据当前位数字将所有元素放入 0~9 十个桶中，再按照桶的顺序依次取出；之后处理十位、百位……直到最高位处理完成。
```py
def radixSort(nums: List[int]) -> List[int]:
    if len(nums) == 0:
        return nums
    
    # 1、找到最大数
    max_num = max(nums)
    # 2、从个位开始
    exp = 1
    # 3、循环条件：直到最大数取完
    while max_num // exp > 0:
        #4、设置0-9个桶
        buckets = [[] for _ in range(10)]

        # 5、从个位开始按当前位数放入对应桶
        for num in nums:
            # 获取当前位数的数字
            digit = （num // exp）% 10
            buckets[digit].append(num)
        
        # 6、按0-9的顺序重新收集
        index=0
        for bucket in buckets:
            for num in bucket:
                nums[index] = num
                index += 1
        
        # 7、开始进位：个位 -> 十位 -> 百位
        exp *= 10
    
    return nums
```

# 堆排序
时间复杂度：O(n log n)<br>
空间复杂度：O(1)<br>
最好：O(n log n)<br>
最坏：O(n log n)<br>
稳定性：不稳定

设计思路：升序排序时，首先将整个序列调整成一个大根堆，使堆顶元素成为当前序列中的最大值。然后将堆顶元素与当前待排序区域的最后一个元素交换，这样最大元素就被放到了最终位置。接着缩小堆的范围，并重新调整剩余元素，使它们再次构成大根堆。之后继续取出堆顶最大元素放到末尾。每进行一轮，就有一个最大元素确定最终位置，直到整个序列有序。
```py
# 将数组变为大根堆的形式
def heapif(nums: List[int], n: int, i: int) -> List[int]:
    # 假设当前节点 i 是最大值
    largest = i
    # 左孩子和右孩子的下标
    left = 2 * i + 1
    right = 2 * i + 2

    # 找到当前节点，左孩子，右孩子中的最大值
    if left < n and nums[left] > nums[largest]:
        largest = left
    if right < n and nums[right] > nums[largest]:
        largest = right
    
    # 如果最大值不是当前节点，则交换并继续向下调整
    if largest != i:
        nums[i], nums[largest] = nums[largest], nums[i]
        heapif(nums, n, largest)

# 堆排序
def heapSort(nums: List[int]) -> List[int]:
    n = len(nums)
    # 1、建立大根堆
    for i in range(n//2-1, -1, -1):
        heapif(nums, n, i)
    
    # 2、不断去除堆顶最大元素
    for i in range(n-1, 0, -1):
        # 交换堆顶和数组末尾的元素
        nums[0], nums[i] = nums[i], nums[0]

        # 除去堆尾元素继续构建大根堆
        heapif(nums, i, 0)
```
