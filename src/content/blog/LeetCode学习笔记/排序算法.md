# 直接插入排序
时间复杂度：平均 O(n²)<br>
空间复杂度：O(1)<br>
最好：O(n)<br>
最坏：O(n²)<br>
稳定性：稳定<br>

代码设计思路：将整个序列分为前面的有序区和后面的无序区。开始时只把第一个元素看作有序区，然后每次从无序区取出第一个元素，与有序区中的元素从后向前进行比较。比它大的元素依次向后移动，直到找到一个不大于它的元素，再将当前元素插入到该位置之后。每完成一次插入，有序区就增加一个元素，直到整个序列有序。
```py
def insertSort(nums: List[int])->List[int]:
    for i in range(1,len(nums)):
        temp=nums[i]
        j=i-1

        while j>=0 and nums[j]>temp:
            nums[j+1]=nums[j]
            j -= 1
        
        nums[j+1]=temp
    return nums
```

# 希尔排序
时间复杂度： O(n²)<br>
空间复杂度：O(1)<br>
最好：与增量序列有关<br>
最坏：O(n²)<br>
稳定性：不稳定

设计思路：先选取一个较大的增量，将相隔该增量的元素划分到同一组中，并分别对每一组进行直接插入排序。完成一轮之后逐渐减小增量，再重新分组并进行插入排序。随着增量不断减小，整个序列会逐渐趋于有序。最后当增量减小到 1 时，相当于对整个序列进行一次直接插入排序
```py
def shellSort(nums: List[int])->List[int]:
    gap=len(nums) // 2
    while gap > 0:
        for i in range(gap, len(nums),gap):
            temp=nums[i]
            j=i-gap
            while j >= 0 and nums[j] > gap:
                nums[j+gap]=nums[gap]
                j -= gap
            nums[j+gap] = temp
        gap = gap // 2
    
    return nums
```

# 冒泡排序
时间复杂度：平均 O(n²)<br>
空间复杂度：O(1)<br>
最好：O(n)<br>
最坏：O(n²)<br>
稳定性：稳定

设计思路：从序列前面开始，依次比较相邻的两个元素。如果前一个元素大于后一个元素，就交换它们的位置。这样不断向后比较和交换，一趟结束后，当前未排序部分中最大的元素会移动到最后的位置。下一趟只需要对前面尚未排序的部分继续进行相邻比较。每完成一趟，就有一个最大的元素确定最终位置，直到所有元素都有序。
```py
def bubbleSort(nums: List[int])->List[int]:
    for i in range(len(nums)-1):
        for j in range(len(nums)-i-1):
            if nums[j] > nums[j+1]:
                temp = nums[j]
                nums[j]=nums[j+1]
                nums[j+1]=temp
    return nums
```

# 简单选择排序
时间复杂度：O(n²)<br>
空间复杂度：O(1)<br>
最好：O(n²)<br>
最坏：O(n²)<br>
稳定性：不稳定

设计思路：将序列分成前面的有序区和后面的无序区。开始时有序区为空，每一趟都在无序区中寻找最小的元素，然后将这个最小元素与无序区的第一个元素交换。这样每完成一趟，就会把一个最小元素放到它最终应该处于的位置，有序区扩大一个元素，无序区减少一个元素。重复这个过程，直到所有元素排列完成。
```py
def selectSort(nums: List[int]) -> List[int]:
    for i in range(len(nums)-1):
        min_num=i
        for j in range(i+1, len(nums), 1):
            if nums[j] < nums[min_num]:
                min_num=j
        temp=nums[i]
        nums[i]=nums[min_num]
        nums[min_num]=temp
    return nums
```
