# 题目描述
给定一个未排序的整数数组 **nums**，找出数字连续的**最长序列**（不要求序列元素在原数组中连续）的长度。
请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

**示例 1：**<br>
&emsp; **输入：** nums = [100,4,200,1,3,2]<br>
&emsp; **输出：** 4<br>
**解释：** 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。<br>

**示例 2：**<br>
&emsp; **输入：** nums = [0,3,7,2,5,8,4,6,0,1]<br>
&emsp; **输出：** 9<br>

**示例 3：**<br>
&emsp; **输入：** nums = [1,0,1,2]<br>
&emsp; **输出：** 3<br>

# 我的解法
## 设计思路
先将数组转换为哈希集合，遍历时通过判断 `x - 1` 是否存在来找到连续序列的起点。再从起点开始依次查找后续连续数字，并更新最长序列长度。

## 代码实现
```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        nums_set=set(nums)
        max_len=0
        for num in nums_set:
            if num-1 not in nums_set:
                i=1
                while num+i in nums_set:
                    i +=1
                max_len=max(max_len,i)
        
        return max_len
```
